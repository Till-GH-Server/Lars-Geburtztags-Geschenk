# Lars – Geburtstagsgeschenk

Die Geburtstags-Webseite liegt in `index.html`. Sie enthält die zuletzt bearbeitete Version inklusive des eingebetteten DramaLama-Banners und der Download-Funktion.

## GitHub Pages aktivieren

1. Öffne **Settings → Pages**.
2. Wähle bei **Build and deployment → Source** die Option **GitHub Actions**.
3. Der Workflow unter `.github/workflows/pages.yml` veröffentlicht die Website bei jedem Push auf `main`.

**Hinweis:** Dieses Repository ist aktuell privat. Bei GitHub Free muss ein Repository für GitHub Pages öffentlich sein. Bei einem privaten Repository ist Pages nur mit einem passenden kostenpflichtigen Tarif verfügbar. Auch dann ist die veröffentlichte Website öffentlich erreichbar.
